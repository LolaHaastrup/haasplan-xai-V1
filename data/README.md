# Framework artefacts

These files are produced by **Module 9** of the Colab notebook
(`save_artifacts()`), which writes them to `/content/`.

The app requires four of them:

| File | Produced from |
|------|---------------|
| `bus_train_plan.json` | `STEPS` |
| `bus_train_S8_PSA.json` | `S8_RESULT` |
| `bus_train_CQ_results.json` | `CQ_RESULTS` |
| `bus_train_AF_labels.json` | `LABELS` |

Download them from Colab and commit them here. The app will refuse to start
and will name the missing file if any are absent.

Because these artefacts are generated by the same pipeline that the notebook's
scenario and competency question tests verify, the app is evaluating the
verified system rather than a reimplementation of it.
